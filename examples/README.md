# 人工验证样例

本目录的向量和ID均为人工构造，没有真实图片、语义编码或训练输出。用于检查余弦排序及指标计算，不能作为实验结果。

`evaluation/`提供12个虚构图片ID、16条虚构查询及三份人工排名，带完整protocol/run契约，用于验收分类统计、MRR@10、改善/退化、选例覆盖和表格。所有文件声明`data_kind=synthetic`，不是E0/E1/E2真实模型结果；运行命令见[排名契约](../docs/ranking-contract.md)。

查询应依次返回synthetic_a、synthetic_b、synthetic_c，分数约为1、0.6、0。

评测样例共有2条查询，第一条首位命中、第二条第二位命中，因此R@1=0.5、R@5=1.0、R@10=1.0，所提供排名内的MRR=0.75。排名深度为3，正式报告应标明MRR@3。
