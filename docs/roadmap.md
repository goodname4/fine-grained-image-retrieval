## 四人共同工作与数量

共同工作已包含在各人的25点中，不额外增加总量。

- **细粒度标注**：每人初标25条，共100条；A与B互审，C与D互审，每人另复核25条。每条查询有初标和独立复核，争议由A组织讨论。无法完整标注相关图片时，按候选池评测记录限制。
- **负样本抽检**：B组织，A协助检查规则，C检查训练输入；明确哪些已核对、哪些仍可能是假负样本。
- **报告**：A写数据和实验结果，B写基线与检索，C写训练与改进，D写系统实现并整合格式。摘要、结论与局限共同核对。
- **答辩**：每人讲解自己模块，四人均需理解全流程；只展示真实实现与结果。

## 接口与责任边界

| 交接 | 交接物 | 责任界限 |
| --- | --- | --- |
| A → B/C | 数据清单、固定划分、训练/验证输入格式 | A保证数据协议；B/C不自行改变划分 |
| B → C | 原始图文特征、模型摘要、训练负样本 | B负责特征与候选；C负责适配和损失 |
| C → B/D | 适配层checkpoint、结构配置、加载接口 | C保证可加载；B生成匹配索引，D接入应用 |
| B/C → A | 各方法排名、配置与模型标识 | A统一评测，不混合不同候选库结果 |
| A/B/C → D | 数据规范、编码/检索组件、模型与指标产物 | D负责集成、展示和性能，不替代算法负责人 |
