# 开发计划与分工

计划起点为2026-10-16。开题为10月22日或24日，依课程安排确定；最终截止日期尚未给出。以下日期为内部目标。

## 开题前：10月16—21日

- [x] 明确题目、范围、技术路线及研究问题。
- [x] 建立仓库、说明文档和可运行的基础检索/指标工具。
- [ ] 确认老师允许本地使用开源预训练模型。
- [ ] 确认成员、硬件、查询语言与数据来源。

没有跑出的初步结果应写“计划”，不能用人工向量结果替代。

## 第1周：10月16—22日

重点：数据与真实基线。完成数据检查、固定划分、本地模型加载、图文编码、索引与Recall评测。验收：真实查询可检索真实图片，E0协议固定。

## 第2周：10月23—29日

重点：适配训练与最小软件。实现残差层、批采样、对比损失、验证集早停、checkpoint和基础Streamlit界面。验收：E1可重复运行，界面能检索，完成两周版本报告。

两周版本应包含E0/E1实测、主要失败案例和运行说明。困难负样本尚未实现时，明确列为后续工作。

## 第3周：10月30日—11月5日

重点：困难负样本与细粒度分析。完成训练集挖掘、抽样复核、E2、测试子集标注及分类评测。验收：三种方案同协议比较，能够解释至少几类错误。

## 第4周：11月6—12日

重点：复现、比较界面、报告。预算允许时增加种子重复；完善基线/改进并排展示、环境说明、实验表、演示和书面报告。只有必做项完成后再做图搜图或增量索引。

## 分工建议

人数未定，以下按责任域划分，不指定成员：

| 责任域 | 主要工作 | 可交付物 |
| --- | --- | --- |
| 数据与评测 | 清洗、划分、细粒度标注、指标、错误分析 | 数据协议、评测脚本、结果表 |
| 模型与训练 | 编码器、适配层、损失、负样本、实验 | 特征缓存、训练代码、checkpoint与日志 |
| 系统与复现 | 索引、界面、配置、性能、文档 | 可运行系统、运行说明与演示 |

两人团队可合并责任域；每人都应能说明核心方法。报告和答辩共同完成，保留真实贡献记录。

## 主要风险与处理

| 风险 | 处理 |
| --- | --- |
| 模型或数据无法及时获取 | 开题前完成可访问性验证，固定一个可获得版本 |
| CPU编码过慢或显存不足 | 小批量测量、缓存特征、缩小数据；不先做全参数微调 |
| 训练后效果下降 | 验证集调学习率/容量，检查过拟合与假负样本；如实报告 |
| 中文支持成本超出计划 | 先完成与数据一致的英文版本，再独立规划中文 |
| 困难标注耗时 | 固定小型细粒度子集，记录未完全标注的限制 |
| 界面占用过多开发时间 | 先做查询和比较，用成熟组件，暂缓账户和部署 |
