# 新版开题汇报提纲

research-v2，2026-10-27。完整正文见[proposal-report.md](proposal-report.md)，实施说明见[implementation-plan.md](implementation-plan.md)。汇报日期及成员/教师信息按实际填写。

题目：**面向组合语义理解的自然语言图像检索：实体关系监督与语义一致性轻量训练**。

## 一句话介绍

基于2026年的组件语义监督研究，我们计划构建本地图文检索系统，通过实体关系解析、最小语义编辑及文本LoRA训练，研究模型能否同时区分关键语义变化并保持同义表达稳定。

## 常见问题与回答

**NLP工作具体在哪里？**

有对象绑定的实体/属性/有向关系解析、保持原意的改写、改变一个条件的语义编辑、文本Transformer内部LoRA训练，以及解析/语义区分/改写稳定性评测。语言内容直接决定训练监督，不只在输入处编码一次。

**研究够新吗？**

主要依据CS-CLIP的2026年工作及2026-10-23更新版，参考RePair等2026年研究。近期方法的复现适配与发表级原创不同，本项目只将经对照实验支持的增量作为结论。[CS-CLIP](https://arxiv.org/abs/2602.23906)、[RePair](https://arxiv.org/abs/2608.29604)。

**和CS-CLIP有什么不同？**

本项目在Flickr8k与受限算力下研究文本LoRA的组件监督及显式同义一致性。原论文已有文本侧微调消融，不能把只训练文本当作新发明，也不声称完整复现原论文大规模设置。N1/N2/N3实验检验本项目具体选择是否有价值。

**为什么保留双编码器？**

保留本地检索效率，将新工作落实到编码器内部的语言表示和训练信号。NLP相关性由研究任务、训练和评测体现，不取决于是否放弃双编码架构。

**如何证明不是增加数据带来的收益？**

N0—N3共享全句正例池，N1/N2共享同一批编辑，N2/N3共享同义文本曝光，只改变指定目标；参数结构、步数和调参预算控制一致。

**如果没有提升？**

按固定规则保留结果，检查语义解析、假负例、短句偏好及图像歧义，报告改善与退化。不得换测试集或覆盖旧结果来制造收益。
