# 新版实验设计与结果记录

版本research-v2，2026-10-27。E0/E1/E2为已有历史实验；N0—N3未训练、无真实成绩。旧数据见[前期训练报告](reports/c-training-and-ablation.md)，新训练实施见[迁移计划](implementation-plan.md)。

## 1. 冻结协议与控制变量

沿用flickr8k-v1 cleaned：train5998图/29990描述，val及test各1000图/5000描述。源图及所有组件、改写、错误变体必须在同一划分。

只用train构建优化样本及失败驱动候选；val负责权重、早停和配置选择。正式test在配置及标注冻结后评价。既有100条test细粒度草稿已被查看/辅助标注，应披露接触情况；不把它改名为全新未见集合，也不据其错误选择方法。

所有N实验保持基础CLIP、LoRA层/rank、冻结规则、采样种子、更新步数及验证预算一致。保持全句正例池一致，包含相同原句和经核验同义变体；N2/N3的文本曝光一致，只改变显式一致性项。N1/N2使用相同单条件编辑及对应源图，披露句长和token/前向计算差异。

| 方法 | 训练内容 | 主要比较 |
| --- | --- | --- |
| E0 | 原始CLIP | 零样本历史基线 |
| E1/E2 | 原有MLP与困难图片负样本 | 保留已完成工作，不与N系列单独归因损失 |
| N0 | 文本LoRA，完整句对齐 | 语言侧训练基线 |

N2是CS-CLIP思想的受限资源实现，不是原论文全量复现。外部预训练checkpoint只能另列参考，其训练数据不同，不能当作同数据受控实验。

## 2. 数据规模和试点

先构建约30张val源图的语义样本组，训练数据从train独立生成。试点检查解析/变体有效率、视觉可判定性、显存和训练闭环，不用于正式test成绩。

资源允许时，以100—200张test源图构建固定诊断组，每组包含原句、同义句、单条件错误句，以及可用的正确/错误追加细节。优先覆盖属性绑定和非对称关系；某图不支持某种编辑时标记not_applicable，不强造负例。按源图统计样本量和不确定性，不把同图多个改写作为独立图片样本。

训练规模由train候选质量和成本决定，保存各现象采纳/拒绝/未审数量。训练负例最低通过人工或记录了图片证据的自动核验；自动核验可靠性由独立人工抽检估计，未审与歧义负例不进入默认训练。正式诊断全部独立人工复核。

## 3. 优化与checkpoint选择

起始配置为待试验：文本注意力末两层q_proj/v_proj、LoRA rank4/alpha8、固定tau0.07、micro-batch8、累积4步、AdamW学习率1e-4、最多10epoch、patience3、梯度裁剪1.0。不能将micro-batch8累积4步宣传为具有32个对比负例：若未实现跨微批次特征队列，InfoNCE分母仍限于当前微批次。

lambda_s与lambda_u先取0.2；lambda_p先取0.1，均按有效编辑均值归一化。这些仅为设备试点起点，必须在正式比较前统一冻结可比较配置，不从旧MLP的0.001学习率和8秒耗时推断新训练。

建议固定选择顺序：

1. 用N0的val标准检索表现确定可比较的基础结构和优化设置。
2. 限定小规模、等预算验证搜索选择损失权重，记录所有尝试和选择依据。
3. 每次训练按val属性绑定/关系方向诊断宏平均准确率选择checkpoint；要求val R@1不低于同种子N0参照超过1.0个百分点。该容忍值是待冻结的研究取舍，不是保证结果。
4. 合格checkpoint并列时比较val R@1、完整MRR，再保留较早epoch；epoch0也参与。如果没有满足约束的checkpoint，报告该方法失败，不为test换规则。
5. 正式种子目标42/43/44；报告每次结果、均值和样本标准差。损失方差与按源图bootstrap的查询不确定性分开解释。

如研究团队调整上述选择规则，必须在正式测试前写入配置和报告，不事后根据test决定主指标。

## 4. NLP指标的可执行定义

| 指标 | 定义与解释 |
| --- | --- |
| 实体/关系解析 | 独立人工金标，实体跨度/规范化实体、属性所属对象、有向关系三元组分别统计precision/recall/F1 |
| 最小编辑区分准确率 | 对同图的正确/错误文本，s_right>s_wrong记1，反向记0，并列记0.5；按编辑类型及源图宏平均 |
| Half-truth诊断 | 仅对看图确认的错误新增细节，计算正确短句优于错误追加句的比例；使用同样并列规则 |
| 正确追加细节对照 | 同时报告真实追加与错误追加的分数变化及等长正确/错误对区分，不能把所有长描述降分解释为理解提升 |
| 同义共同命中率 | 一组原句与同义句均在Top-K命中同一已标注源图/相关项时记1 |
| 同义排名差 | 在两句均有完整排名时计算首个已知相关项排名差绝对值，另报双方R@K，不单独以低分数差或Top-K重叠证明理解 |
| 编辑后的检索语义 | 对具有独立相关图标注的编辑查询另行检索；不能把错误句对原图不匹配误当成该查询无相关图 |

SugarCrepe++可作为外部匹配诊断，按官方任务单列准确率；不与整库检索R@K合并。检查外部数据与本地训练图像重叠，披露预训练污染难以完全排除的限制。

## 5. 标准检索、成本与不确定性

标准test仍使用固定1000图、5000条原始描述；R@K为Top-K命中任一已标注相关项的查询比例，完整MRR使用1000项排名。缺失查询、重复ID及错配摘要报错；显式空结果记零并记录原因。源图配对不证明其他图不相关。

LoRA参数量、训练前向/token数、纯训练及验证导出耗时、峰值显存、缓存占用分别记录。单独列出离线语言生成/核验成本，不能隐入训练收益。

查询预热后重复测p50/p95，记录设备、K、图库规模及样本数；GPU计时同步；冷启动、编码、排序与端到端分开。按源图成对bootstrap，不将同图多句视为独立样本。语义诊断输出每项分数差、来源组及失败原因。

## 6. 必做消融与选例

- N1对N2：同一批编辑从全句监督变为组件监督，观察现象级变化。
- N2对N3：数据曝光相同，仅切换显式同义一致性项。
- N2去掉关系监督：判断关系方向收益是否来自该监督，记录有效样本量变化。
- 真/假追加及长度匹配对照：排除短句或模板偏好。

至少12个真实案例，覆盖属性绑定、角色/方向、同义改写和错误追加；同时展示改善、失败和退化。原始与同义句共同失败、解析错、负例误判、图像歧义及语言表示失效分别归因。可选失败驱动采样必须与随机选择同数量、同编辑类型样本比较。
