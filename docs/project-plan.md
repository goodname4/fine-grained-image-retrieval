# 新版项目计划：组合语义理解与语言侧轻量训练

版本：research-v2；更新日期：2026-10-27。用户已确定采用本路线；N0—N3仍待实现和实测。实施清单见[代码迁移计划](implementation-plan.md)，开题正文见[开题报告](proposal-report.md)。

## 1. 项目定位

题目：**面向组合语义理解的自然语言图像检索：实体关系监督与语义一致性轻量训练**。

建立本地英文文本搜图系统，研究两个可分离的问题：

- Q1：在相同文本LoRA结构下，实体与关系组件监督是否比完整句负例监督更有利于属性绑定、关系方向和错误追加细节的区分？
- Q2：显式同义一致性约束能否减少措辞变化造成的排序波动，同时保留关键语义变化的区分能力及总体检索表现？

采用2026年CS-CLIP的组件监督思想作为方法基础，研究受限资源条件下的实现与扩展。实体解析、最小语义负例、文本侧训练、LoRA本身均不作为原创声明；CS-CLIP已有文本侧微调消融。本项目的增量结论由同设置实验支持，发表级原创性尚未确认。

近期研究与引用见[路线依据](research-redesign.md)。RePair用于可选的失败驱动采样研究，EviRank和Qwen3-VL重排序用于备选比较，不纳入首版必做。

## 2. 方法与范围

训练流程：

原始训练描述 → 实体/属性绑定/有向关系解析 → 同义变体与单条件错误变体 → 图片依据核验 → 文本编码器内LoRA训练 → 验证集选择 → 固定测试。

推理流程：

本地英文查询 → 对应文本LoRA编码 → L2归一化 → 与冻结图像分支的原始索引计算余弦相似度 → Top-K。

训练中的语言解析和变体构建离线执行；在线查询不强制调用生成式模型。首版保留CLIP ViT-B/32与精确检索；核心语义现象为属性绑定及非对称关系。数量、否定、中文、主动补查、大模型重排序和图像生成列为扩展，不同时实施。

图片分支及投影层冻结，只更新文本注意力内LoRA参数。原始图片向量可复用；旧的整句NumPy缓存不能用于更新文本编码器。图片向量不变不代表现有版本校验自动支持N系列，仍须扩展制品契约。

## 4. 实验方案

| 实验 | 共同文本训练结构 | 差异 |
| --- | --- | --- |
| E0/E1/E2 | 历史冻结编码/MLP方案 | 保留历史对照，不用于单独归因新损失 |
| N0 | 相同文本LoRA、相同全句正例池 | 仅完整句图文对齐 |
| N1 | 同N0 | 增加完整句最小语义负例监督 |
| N2 | 同N0 | 对同一批编辑增加组件及对应错误变体监督 |
| N3 | 同N2 | 增加显式同义一致性项 |

N0—N3共用源图、原句与通过核验的同义正例池。N2与N3都处理同一批同义文本，N3仅改变一致性项权重，避免把多看数据误当作新损失收益。N1/N2使用同一批单条件编辑，控制更新步数、参数量和调参预算，记录token与前向开销差异。

训练目标、选择规则、长度与真实追加细节对照见[实验设计](experiments.md)。正式配置冻结后目标为3个配对种子，资源不足则披露实际种子数。

## 5. 交付阶段与验收门槛

不预设完成日期；各阶段按产物验收。

| 阶段 | 主要交付 | 继续条件 |
| --- | --- | --- |
| P0 协议与验证试点 | 约30张val源图的解析、同义及最小编辑样本，人工核验记录 | 引用、编辑位置、对象绑定与真假依据可追溯；排除歧义样本 |
| P1 训练闭环 | 小batch文本LoRA、梯度/冻结检查、保存重载及旧流程回归 | LoRA有效更新，图片分支不变，显存可容纳，重载输出一致 |
| P2 受控实验 | N0/N1/N2，再加入N3和必要消融 | 输入量与优化预算可比较；有改善或退化均有逐项证据 |
| P3 固定测试与集成 | 冻结配置、配对种子、标准排名、语义诊断、真实界面 | 测试不参与调参，错配拒绝，模型切换不污染结果 |
| P4 报告与交付 | 实验记录、至少12个改善/失败/退化案例、环境与启动说明 | 报告、代码和制品摘要对应，不写未经运行的效果 |

若P0数据质量不足，先修数据；若P1显存不足，减micro-batch、缩小LoRA范围并实测梯度累积；若P2无收益，分析假负例、解析错误及图像不可辨识性，不以增加大量模块替代问题诊断。

## 6. 评价与验收

必须同时交付：

1. 原始5000条描述/1000图的标准R@1/5/10与完整MRR。
2. 组件正确/错误变体区分、属性绑定及关系方向分项结果。
3. 同义查询共同命中率与源图排名差；稳定地返回错误结果不算理解改善。
4. 错误追加细节诊断，以及正确追加和长度匹配对照。
5. 语义解析质量、人工复核比例、训练参数/时长/峰值显存、在线p50/p95。
6. 可加载的LoRA、固定制品摘要、真实排名和可演示本地软件。

语义匹配准确率与整库检索R@K分开报告。相关性标注不完整时说明已知源图或候选池范围；不能自动把未标注图片或未提及条件当作负例。
