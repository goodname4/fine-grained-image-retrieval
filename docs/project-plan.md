# 详细项目方案

## 定位与目标

本项目属于NLP中的跨模态检索任务：从文本语义出发，在图像集合中寻找相关结果。关注文本编码、图文对齐、对比学习、负样本设计与检索评价，并通过软件界面呈现实验结果。

预期用户是需要通过描述查找图片的学习者或图库使用者。工作重点是研究自然语言细节对检索的影响，不限定医疗、遥感等需要专门知识与数据的领域。

目标是完成可复现的本地检索闭环，并检验一种轻量改进。性能提升属于实验假设；若未提升，应如实分析过拟合、数据规模、假负样本或预训练分布差异。

## 使用流程

1. 管理者准备具有使用权限的图片和图文标注。
2. 系统检查清单，固定数据划分并记录摘要。
3. 离线提取图片与训练文本特征；记录模型、预处理和数据版本。
4. 运行零样本基线；在训练集训练适配层，在验证集选择超参数。
5. 使用相同测试协议评估E0/E1/E2。
6. 用户在界面输入查询、选择模型与Top-K，查看图片和排名。
7. 对比模式同时展示基线与改进结果，支持记录错误案例。

## 功能模块与验收

| 模块 | 计划实现 | 验收标准 |
| --- | --- | --- |
| 数据准备 | 导入清单、检查路径、ID、划分、损坏图片 | 不同划分的image_id无交集；报告失败项，不静默跳过 |
| 本地编码 | 图文编码、批处理、缓存 | 权重在本地时可断网；重跑缓存得到一致索引 |
| 基线检索 | 特征归一化、余弦排序、Top-K | 查询可返回实际图片；K超图库大小时安全截断 |
| 适配训练 | 冻结主干、训练小型残差层 | 记录可训练参数、损失、种子、验证指标、checkpoint |
| 困难负样本 | 训练集挖掘、排除已知正样本、抽样复核 | 保存候选来源、过滤规则及复核比例 |
| 评测 | 标准检索与细粒度子集 | 同协议对比；输出可机器读取的指标与逐查询结果 |
| 界面 | 查询、模型选择、并排对比 | 显示真实图片、图片ID、排名、分数和耗时 |
| 复现 | 环境、配置、数据版本、训练与评测步骤 | 新环境可按说明复现，不依赖硬编码个人路径 |

## 核心工作量来源

- 自建数据检查与索引流水线，而非只展示预训练模型输出。
- 训练轻量适配层，独立控制训练参数与验证流程。
- 实现并验证困难负样本策略，识别假负样本问题。
- 构建细粒度标注和错误分析，解释总体指标之外的表现。
- 实现真实图片的本地检索软件，以及可复用的评测工具。

## 范围控制

基础版本只支持一个数据集、一套模型、一种适配层、一种负样本策略。只有核心闭环完成后才增加中文、图搜图和增量索引。首版不实现用户账户、云部署、生成式回答或实时视频。

硬件尚未确认，不预先承诺显存和训练时间。开始时记录CPU、GPU、内存及版本，用小批量实测编码与训练，再决定批大小。没有GPU时优先缩小数据做CPU基线与缓存特征训练；若速度不满足周期，应缩减实验，不虚报完成状态。

## 交付清单

团队共4人：A负责数据与正式评测，B负责本地编码、检索基线和负样本挖掘，C负责适配与训练，D负责软件与集成。工作量共100点、每人25点；子任务和交付物见[四人分工与工作量](roadmap.md)，不另设完成时间安排。

- 源代码、版本化配置、依赖与运行说明。
- 数据来源、许可说明、划分清单或可重建的脚本。
- 预训练权重来源及本地准备步骤，不把大权重写入Git。
- E0/E1/E2的真实结果、逐查询记录、失败案例。
- 可演示界面及演示脚本。
- 书面报告：摘要、背景、相关工作、方法、系统实现、实验、局限与分工。

## 完成标准

有真实图文输入、真实图片检索结果、独立训练过程与有效评测，能够解释改进有效或无效的原因。初始化仓库、人工向量示例和文档本身不算最终系统完成。
