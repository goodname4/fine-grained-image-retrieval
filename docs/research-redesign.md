# 新路线选择与研究依据（已采纳）

决策更新：2026-10-27。用户已选择本路线，正式执行以[项目计划](project-plan.md)、[开题正文](proposal-report.md)、[实验设计](experiments.md)及[实施清单](implementation-plan.md)为准。N0—N3尚未实现，本文件不代表新结果。

## 1. 选定方向

题目：**面向组合语义理解的自然语言图像检索：实体关系监督与语义一致性轻量训练**。

采用2026年CS-CLIP组件监督思想，以实体/属性绑定/有向关系解析、最小语义编辑和同义表达为训练材料，在文本编码器内做LoRA更新。研究同一训练结构下的监督粒度，以及显式同义一致性是否兼顾语义敏感性和检索稳定性。

已有数据管线、图片编码、索引、E0/E1/E2结果与软件代码复用。原先讨论的主动证据补查/大模型重排序降为扩展，不与训练主线同时作为必做。

## 3. 新意与NLP相关性的准确表述

NLP工作进入语言数据、训练前向和评测：解析绑定属性及有向关系，区分同义与语义改变，更新文本Transformer内部参数，评价解析和组合语义能力。

不宣称实体解析、反事实负例、只更新文本或同义学习为首次提出。CS-CLIP已有文本侧微调消融；本项目在Flickr8k/受限资源下进行可比较的适配及联合目标实验，不冒充其原文全量设置的复现，也不保证发表级原创。

实验设计的关键为N1/N2共用编辑，N2/N3共用同义文本曝光；只有在固定测试与消融支持时，才陈述监督粒度或一致性项的增量效果。数据质量不足或无收益时先分析原因，不不断叠加新模块。
