# 技术架构与方法

本文件描述整体方法。A的数据/评测、B的本地CLIP编码/检索和C的适配训练已实现；训练实际公式、输入归一化、损失和加载接口以[训练说明](training.md)为准。数据接口见[A交接手册](handoff-a.md)，检索界面由D接入。

## 编码与检索

用本地图像编码器f_I与文本编码器f_T获得同维向量。所有向量做L2归一化，排序分数为点积，即余弦相似度。基线直接使用预训练特征。

图片只在建索引时编码。查询时只编码文本，再计算与图库向量的相似度。第一版采用精确检索，便于检查正确性；后续在真实规模测量后再决定是否引入近似索引。

## 轻量残差适配层

图像与文本分别使用小型残差MLP，输入先归一化：

```text
u = normalize(x)
g(x) = normalize(u + alpha * W2(GELU(W1(u))))
```

编码器冻结，W1/W2可训练。输出维度与原始特征一致，alpha、瓶颈维度及学习率由验证集选择。建议将末层初始化为零，初始行为与基线一致。需记录参数量，并检查训练过程中编码器确实没有梯度。

训练图像适配层后，原有归一化索引不能直接继续使用，需要用对应适配层重新生成。保留原始编码器特征缓存可以避免重复图像编码。

## 对比学习

基础方案为图到文、文到图的对称对比损失。温度参数固定或可学习的选择需写入配置。

每张图片通常具有多条描述，不应将同一图片的其他描述作为负样本。实现可选：

1. 一个batch内每张图片只抽取一条描述，并在epoch间轮换；或
2. 构建多正样本mask，使用支持多正样本的损失。

首版优先采用方案1，避免重复image_id造成错误负样本。实际训练代码应明确执行约束并验证。

## 困难负样本

在训练图库中用基线检索Top-M候选，移除相同image_id与已知相关项，再抽样人工复核。对每条查询选取少量困难负样本，与普通负样本混合；数量、权重由验证集选择。

可以使用单向文本到困难图片的排序辅助损失：

```text
L_hard = mean(max(0, margin + sim(text, negative) - sim(text, positive)))
L_total = L_contrastive + lambda * L_hard
```

困难图片作为辅助损失的候选，不直接当作拥有一一对应文本的样本加入对称对比矩阵。冻结编码器特征仍需经过当前适配层后计算损失。

只在训练集挖掘；固定挖掘策略与候选记录。不能使用测试集人工纠正模型训练。

## 索引与模型一致性

每个真实索引计划包含：image_id、相对图片路径、特征矩阵、模型名称及权重摘要、适配层checkpoint摘要、预处理版本、特征维度、归一化标记、数据摘要和创建时间。

查询侧模型/适配层必须与索引匹配，维度相同仍不足以证明兼容。界面切换模型时同时切换对应文本编码流程和图片索引。
